# Project Title AI and Machine Learning – Practical Exercises

Final project for the Building AI course

## Summary

This project explores Artificial Intelligence and Machine Learning using Python. It includes practical exercises on Bayesian reasoning, optimization, regression, classification, text analysis, and neural networks to understand how AI algorithms solve real-world problems.

## Background

Artificial Intelligence is becoming an important part of everyday life. Machine learning helps computers learn from data, recognize patterns, and make predictions.

The main purpose of this project is to understand the basic concepts of AI and explore how machine learning algorithms work through practical coding exercises.

Problems explored in this project include:

Predicting house and cabin prices using linear regression.
Classifying data using K-Nearest Neighbors (KNN).
Applying Bayesian reasoning to calculate probabilities.
Finding similarities between text documents using TF-IDF.
Understanding neural networks and making predictions.
Using simulated annealing for optimization problems.
## How is it used?

This project is designed for students and beginners who want to learn Artificial Intelligence and Machine Learning.

The exercises use Python programs and datasets to demonstrate how different AI techniques work.

Users can run the Jupyter Notebook, modify the code, experiment with different inputs, and observe the results.

The project can help beginners understand how AI is applied to practical problems such as prediction, classification, and data analysis.

Challenges

This project focuses on basic AI and machine learning concepts. The exercises use relatively small datasets and simplified examples.

Some limitations include:

Predictions may not always be accurate.
Small datasets may not represent real-world situations.
Models can suffer from overfitting.
More testing and real-world data are needed to improve performance.
